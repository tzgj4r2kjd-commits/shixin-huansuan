# 时薪换算器 · 班味版

输入月薪，马上看到你的真实时薪。买任何东西之前，先把它换算成生命小时数——顺便看看你的班味有多重。

## 在线使用

打开 `xinzin_huansuan.html` 即可使用（纯本地运行，无需服务器），或访问 GitHub Pages：https://tzgj4r2kjd-commits.github.io/shixin-huansuan/xinzin_huansuan.html

## 功能

- 输入月薪（唯一必填），实时算出名义时薪与含通勤的真实时薪
- 工作制一键切换：朝九晚五双休 / 大小周 / 996 / 自定义
- 打工人常见商品一键换算：大水 / 瑞幸 / 王者传说皮肤 / 健身卡 / iPhone / 特斯拉
- 班味角色：工时越长，黑眼圈越重（精神 → 疲惫 → 憔悴 → 大爆击），换算时角色吐槽价格
- 一键生成「生命账单卡」PNG，可直接分享
- 所有数据仅存本地浏览器，不上传任何服务器

## 口径

月工作日 = 每周天数 × 4.33；真实时薪把通勤时间也计入「为工作付出的时间」。

## 技术栈

单文件 HTML + 原生 JS + SVG/CSS 动画，零依赖、无 CDN、断网可用。
